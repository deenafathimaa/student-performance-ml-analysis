# student-performance-ml-analysis
End-to-end Student Performance EDA, Linear Regression, Pass/Fail Classification, model evaluation, and data-driven insights using Python and scikit-learn.

## Overview

This project follows a complete machine learning workflow:

- Exploratory Data Analysis (EDA)
- Data quality assessment
- Missing-value and outlier analysis
- Correlation and relationship analysis
- Feature preprocessing and encoding
- Linear Regression for `exam_score` prediction
- Pass/Fail Classification using a 50-mark threshold
- Model evaluation and train/test comparison
- Overfitting/underfitting assessment
- Data-driven student performance insights

## Dataset

The project uses the Student Performance dataset supplied for the Day 18 & 19 assignment.

The dataset is used as provided without fabricating additional records or columns.
